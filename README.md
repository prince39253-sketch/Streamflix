# Streamflix 🎬

Streamflix is a frontend web application that replicates the modern Netflix streaming interface. Built entirely from scratch using pure HTML, CSS, and Vanilla JavaScript with zero external libraries or frameworks.

## 🌟 Highlights
- **Responsive Layout:** Works smoothly across desktop, tablet, and mobile browsers.
- **Hero Banner:** Carousel showcasing featured movies and series.
- **Media Rows & Top 10:** Scrollable media tracks with hover previews.
- **My List:** Save titles to your personal watchlist using browser local storage.
- **Instant Search:** Search titles, genres, and tags in real time.
- **Detail Modal & Player:** View title details, genres, recommendations, and a demo video player.

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` in any web browser (or run using Live Server in VS Code).
